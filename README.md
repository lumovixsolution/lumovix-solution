# Lumovix Solution

Official website for **Lumovix Solution** — software company based in Malabe, Sri Lanka.

## Project

The frontend lives in the [`client/`](./client) folder (React + Vite + Tailwind CSS).

```bash
cd client
npm install
npm run dev
```

See [client/README.md](./client/README.md) for full setup, including the Web3Forms contact form.

## Live stack

- React 19 + Vite
- Tailwind CSS v4
- Web3Forms (contact email to lumovixsolution@gmail.com)
